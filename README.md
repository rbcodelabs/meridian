# Obsidian Setup

One-click installer for the team Obsidian vault.

## Install

Paste this in Terminal:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/rbcodelabs/ObsidianSetup/main/install.sh)"
```

That's it. The app will download, install to `/Applications`, and launch automatically.

## What it does

1. Downloads the team vault from GitHub
2. Extracts it to a location you choose (default: `~/Documents/TeamVault`)
3. Registers it with Obsidian
4. Prompts you to restart Obsidian

## What's included

- Claude Threads
- Google Docs Sync
- Linear Integration  
- Kanban Bases View
- 15+ community plugins (Dataview, Tasks, Templater, QuickAdd, and more)

## Requirements

- macOS 13+
- [Obsidian](https://obsidian.md) installed
